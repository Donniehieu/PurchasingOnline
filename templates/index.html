Khóa API và cấu hình

Khóa lưu trong file data/settings.json trên máy chạy app, không đưa lên GitHub. Ô để trống nghĩa là giữ nguyên. Giao diện chỉ hiện khóa đã che bớt. Google và Brave không có đăng nhập tài khoản để cấp quyền (không dùng OAuth), nên cách duy nhất là dán khóa vào đây.

Google

Hướng dẫn lấy khóa Google (đọc kỹ cảnh báo)

Cảnh báo: Google đã đóng Custom Search JSON API với khách hàng mới (ngừng hẳn từ 01/01/2027). Dự án mới thường bị lỗi 403 dù làm đúng các bước. Nếu nút "Thử kết nối" báo 403, hãy dùng Brave.

  1. Vào console.cloud.google.com, đăng nhập Google, tạo một Project mới.
  2. Menu APIs & Services → Library, tìm Custom Search API, bấm Enable.
  3. Menu APIs & Services → Credentials → Create credentials → API key. Sao chép khóa, dán vào ô "Google API key" bên dưới.
  4. Vào programmablesearchengine.google.com, bấm Add, tạo công cụ tìm kiếm. Mở công cụ vừa tạo, sao chép Search engine ID, dán vào ô "Search engine ID (cx)".
  5. Bấm Lưu cài đặt rồi Thử kết nối. Hạn mức miễn phí trước đây: 100 lượt/ngày.

Brave Search

Hướng dẫn lấy khóa Brave
  1. Vào brave.com/search/api, tạo tài khoản và chọn gói Search.
  2. Theo các nguồn tôi tìm được, gói mới tính theo lượng dùng, có khoảng 5 USD tín dụng mỗi tháng (khoảng 1.000 lượt) và có thể yêu cầu thẻ thanh toán. Hãy xác nhận trên trang giá chính thức của Brave.
  3. Trong trang quản lý (Dashboard), mục API Keys, tạo khóa và sao chép (gọi là subscription token).
  4. Dán vào ô bên dưới, bấm Lưu cài đặt rồi Thử kết nối.

Anthropic (nhận diện ảnh và đọc chữ trong ảnh)

Hướng dẫn lấy khóa Anthropic
  1. Vào console.anthropic.com, tạo tài khoản và nạp tín dụng (tính phí theo lượng dùng).
  2. Mục API Keys, tạo khóa mới (bắt đầu bằng sk-ant-), dán vào ô bên dưới.
