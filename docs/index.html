Khóa API và cấu hình

Trang này chạy hoàn toàn trên trình duyệt. Khóa và dữ liệu chỉ lưu trong trình duyệt của bạn (localStorage), không gửi lên máy chủ của trang. Không dùng chung máy hoặc để người khác mở trình duyệt này khi đã nhập khóa.

Tìm kiếm không cần khóa (tiện ích Cốc Cốc/Chrome)

Khi cài làm tiện ích, app dùng Cốc Cốc và DuckDuckGo mà không cần khóa API, đọc được cả trang cần JavaScript (Shopee, TikTok Shop) bằng cách mở tab nền, và không bị chặn CORS nên không cần proxy. Cốc Cốc mở một tab nền như bạn tự tìm, mỗi lượt vài giây.

Cách app tải trang NCC khi chạy dạng trang web thường

Trình duyệt chỉ đọc trực tiếp được những website cho phép (CORS). Nhiều website chặn, khi đó cần một proxy. Tôi không dùng proxy công cộng mặc định vì kiểm tra thấy các dịch vụ miễn phí không ổn định hoặc đòi khóa. Cách đáng tin cậy là tự triển khai Cloudflare Worker miễn phí của bạn (có sẵn mã trong thư mục tools/).

Hướng dẫn triển khai Cloudflare Worker (khoảng 5 phút)
  1. Đăng ký tài khoản miễn phí tại cloudflare.com.
  2. Vào Workers & Pages → Create → Create Worker, đặt tên, bấm Deploy.
  3. Bấm Edit code, xóa mã mẫu, dán toàn bộ nội dung file tools/cors-worker.js trong repository, sửa dòng ALLOWED_ORIGIN thành địa chỉ trang GitHub Pages của bạn, bấm Deploy.
  4. Sao chép địa chỉ Worker (dạng https://ten.xxx.workers.dev), dán vào ô trên và thêm /?url={url}.
  5. Tick ô đồng ý, bấm Lưu cài đặt, rồi Thử proxy.

Mã Worker chưa được tôi chạy thử trên Cloudflare, hãy thử bằng nút bên dưới.

Google (Custom Search API)

Hướng dẫn lấy khóa Google (đọc kỹ cảnh báo)

Cảnh báo: Google đã đóng Custom Search JSON API với khách hàng mới (ngừng hẳn từ 01/01/2027). Dự án mới thường bị lỗi 403 dù làm đúng các bước.

  1. Vào console.cloud.google.com, tạo Project mới.
  2. APIs & Services → Library, tìm Custom Search API, bấm Enable.
  3. Credentials → Create credentials → API key, sao chép khóa vào ô bên dưới. Nên giới hạn khóa theo địa chỉ trang web của bạn (HTTP referrer).
  4. Vào programmablesearchengine.google.com, tạo công cụ tìm kiếm và sao chép Search engine ID.

Brave Search (qua proxy của bạn)

Hướng dẫn lấy khóa Brave
  1. Vào brave.com/search/api, tạo tài khoản, chọn gói Search.
  2. Theo các nguồn tôi tìm được, gói mới tính theo lượng dùng, có khoảng 5 USD tín dụng mỗi tháng (khoảng 1.000 lượt) và có thể cần thẻ. Hãy xác nhận trên trang giá của Brave.
  3. Tạo khóa ở mục API Keys, dán vào ô bên dưới.
  4. Brave chặn gọi trực tiếp từ trình duyệt (tôi đã thử và bị chặn CORS), nên cần cấu hình proxy ở trên.

Anthropic (nhận diện ảnh và đọc chữ trong ảnh)

Hướng dẫn lấy khóa Anthropic
  1. Vào console.anthropic.com, tạo tài khoản, nạp tín dụng.
  2. Mục API Keys, tạo khóa (bắt đầu bằng sk-ant-), dán vào ô dưới. Khóa nằm trong trình duyệt của bạn, hãy đặt hạn mức chi tiêu thấp.
